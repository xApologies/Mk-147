# Alchemy and Genesis Materials
An Alchemist is a Genesis material scientist specializing in materials/substances interacting with Genesis Dust, Genesis energy and Transduction. Alchemy is broader than potion-making.

Products may include beverages/potions, reactive mixtures, agricultural nutrient media, Genesis-infused stock materials, and novel higher-order materials/elements.

Awakening potions are NOT MK-147 canon. MK-147 uses Binding Circles.

Alchemists are upstream material suppliers. Blacksmiths can buy Genesis-infused metal stock. Genesis-infused iron can be stronger, more durable and corrosion-resistant than ordinary iron. Ordinary Type-1 materials remain viable.

Distinguish ordinary material; Genesis-infused ordinary material; genuinely novel higher-order Alchemical material.

Element ladder:
- Type 1: real periodic table.
- Type 2: ~80% discovered; first-order Genesis-material domain. Illustrative mechanism: Type-1 matter + Genesis Dust + sigil-guided Transduction -> stable novel state. Helium-4 + iron + Green Genesis Dust -> stable liquid-iron is illustrative.
- Type 3: ~40% discovered; may arise from Type 1 + Type 2 or Type 2 + Type 2.
- Type 4: ~10–20% discovered.
- Type 5: frontier; only one or two known examples.
Percentages are author-level approximations, not necessarily in-world measurements.

Agricultural velis can accelerate growth/nutrient uptake; Alchemists can produce nutrient-enriched growing media to support increased biological demand.
