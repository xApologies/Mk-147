CORE DESIGN RULE
=========================================================

Genesis is NOT English translated word-for-word.

Genesis is a relationship- rst language.

English asks:

  What is the object?

Genesis asks:

  Where is the boundary?
  What occupies it?
  What relationship persists?
  What identity closes?

=========================================================
BASIC WORD ORDER
=========================================================

Genesis follows a Japanese-like structure:

  TOPIC / CONTEXT
  RELATION
  IDENTITY / EVENT
  VERB / CLOSURE

Default order:

  Context - Relation - Identity - Closure

Closest English approximation:

  Subject - Object - Verb

But Genesis is better understood as:

  Boundary - Relationship - Resolution

Examples:

  English:
    The wagon is red.

  Genesis logic:
    This-boundary wagon red-expression closes.
  English:
    The storm is coming.

  Genesis logic:
    Storm-topic basin-instability propagates.

=========================================================
NO SIMPLE "IS"
=========================================================

Genesis does not naturally use "is" the way English does.

English:

  The wagon is red.

Genesis:

  The wagon expresses red.
  The wagon closes in red.
  The wagon inherits red-basin expression.

English:

  The stool is a stool.

Genesis:

  Identity inherits identity.
  The thing remains itself.

=========================================================
DEMONSTRATIVE SYSTEM
=========================================================

Genesis inherits Japanese-style this / that / over-there logic,
but converts it into boundary logic.

Root demonstratives:

  KA
    this / within my boundary / near speaker

  SA
    that / within your boundary / near listener

  A
      over there / outside both boundaries

  DO
    unknown / unresolved / question-boundary

Core pattern:

  KA = this near me
  SA = that near you
  A = that outside us
  DO = which / what / unresolved

Examples:

  ka-en
    this identity
     this thing here

  sa-en
    that identity near you

  a-en
    that identity over there

  do-en?
    what identity?
    what is that?

=========================================================
DEMONSTRATIVE DERIVATIONS
=========================================================

Thing / identity:

  ka-en      this thing
  sa-en      that thing near you
  a-en      that thing over there
  do-en      which thing?

Place / boundary:

  ka-sha this place / this boundary
  sa-sha that place near you
  a-sha that place over there
  do-sha which place?

Direction / propagation:

  ka-ve      toward here
  sa-ve      toward there near you
  a-ve      toward over there
  do-ve      toward where?

State / condition:

  ka-rin this current persistence
  sa-rin that current state near you
  a-rin that distant state
  do-rin what condition?

They are not separate colors.
They are six rotations of one structure.

  142857
  285714

  571428

  857142

  Red    = 1/7 = 0.142857...
  Orange = 2/7 = 0.285714...
  Yellow = 3/7 = 0.428571...
  Green = 4/7 = 0.571428...
  Blue = 5/7 = 0.714285...
  Violet = 6/7 = 0.857142...

=========================================================
NOUNS
=========================================================

Nouns are usually identity roots.

A noun may be marked with:

  -en identity / thing
  -sha place / boundary
  -rin persistent form
  -ael topology / structure

Example:

  wagon-en
    wagon as an identity

  wagon-sha
    wagon-space / wagon boundary

  wagon-rin
    wagon as persistent object

  wagon-ael
    wagon structure / wagon topology

In casual speech, the su x may be dropped.
